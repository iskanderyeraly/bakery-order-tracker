# Bakery Order Tracker

A small web app for a home baker who takes cupcake and cake orders by Instagram DM.
Python standard library only; data lives in `bakery.db` (created automatically).

## Start it
1. Open a terminal in this folder.
2. Run: `python3 app.py`
3. Open http://127.0.0.1:8000

The app uses fixed rules, no AI.
